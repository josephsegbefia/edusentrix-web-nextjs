# Gradebook & Attendance

Manage student grades and attendance records from the teacher portal. Access the gradebook at `/teacher/gradebook` and attendance at `/teacher/attendance`.

## Gradebook

### Overview

The teacher gradebook allows you to:
- Record grades by class and subject
- Manage continuous assessment (CA) scores and exam scores
- View class-wide performance at a glance

### Accessing the Gradebook

1. Navigate to **Gradebook** from the teacher sidebar
2. Select a **Class Group** from your assigned classes
3. Select a **Subject** to open the grading interface

### Recording Grades

1. Open a class-subject gradebook
2. Enter scores for each student
3. Scores are validated against the grading scale
4. Save to update records

### Grade Types

| Type | Description |
|------|-------------|
| Continuous Assessment (CA) | In-term tests, class work, projects |
| Exam | End-of-term examination scores |
| Overall | Weighted combination of CA and Exam |

## Attendance

### Overview

Track student attendance for your assigned classes:
- **Homeroom Attendance** (`/teacher/attendance/homeroom`): Daily morning attendance
- **Period Attendance** (`/teacher/attendance/period`): Subject-specific period attendance
- **Attendance History** (`/teacher/attendance/history`): View past records

### Taking Attendance

1. Navigate to **Attendance** from the teacher sidebar
2. Choose **Homeroom** or **Period** attendance
3. Select the class and date
4. Mark each student as Present, Absent, Late, or Excused
5. Save the attendance record

### Attendance History

View historical attendance data:
- Filter by date range
- See patterns and trends
- Identify students with attendance concerns

## Analytics

Access class performance analytics at `/teacher/analytics`:

### At-Risk Students

The at-risk identification page (`/teacher/analytics/at-risk`) highlights students who may need additional support based on:
- Low grades
- Poor attendance patterns
- Declining performance trends

### Class Performance

View overall class analytics:
- Average scores by subject
- Grade distribution charts
- Performance trends over time

## Best Practices

1. **Regular Updates**: Record grades and attendance promptly
2. **Consistent Standards**: Use the grading scale consistently
3. **Monitor At-Risk**: Check the at-risk page regularly
4. **Accurate Attendance**: Take attendance at the start of each session
5. **Use Analytics**: Let the data guide your teaching decisions
