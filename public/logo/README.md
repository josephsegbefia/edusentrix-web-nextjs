# Logo Assets

## Required Files

The canonical EduSentrix logo lives at:

- **`/public/edusentrix-current-logo.png`** - Main logo file (recommended: 512x512px or larger, PNG with transparency)

Compatibility copies are still published at:

- **`/public/logo/edusentrix-logo.png`**
- **`/public/logo/edusentrix-logo-transparent.png`**
- **`/public/logo.png`**

## Logo Specifications

The logo component expects:
- **Format**: PNG with transparency
- **Recommended Size**: 512x512px or larger (for high-DPI displays)
- **Aspect Ratio**: Square (1:1) preferred
- **Background**: Transparent
- **File Location**: `/public/edusentrix-current-logo.png`

## Usage

The logo is automatically used in:
1. **AppTopbar** - Top navigation bar (small size with text)
2. **Sidebar** - Desktop and mobile navigation (small size with text)
3. **Sign-in Page** - Authentication page (large size with text)

## Components

- `Logo` - Full logo with optional text
- `LogoIcon` - Icon-only version

Both components support size variants: `sm`, `md`, `lg`, `xl`
