# Lessons Module

The Lessons module takes teachers from an **approved lesson note** through timetable-aligned **week plans**, live **session delivery**, and student study — with optional flashcards, resources, homework, and reflection after each session.

## Lesson notes (planning)

1. Teachers author **lesson notes** in the Lesson Notes workflow (draft → submitted → **approved**).
2. Only **approved** notes can seed a week plan or session in Lessons v2.
3. The note remains the source document; sessions allocate sections and scheme items across the week.

> **Tip:** Link your note to the scheme of work so coverage tracking updates when sessions are completed.

## Week plans & sessions (Lessons v2)

1. Open **Lessons** and use **Create week plan** (or open an existing week from the list).
2. Pick class, subject offering, and calendar week — periods come from the **published class timetable**.
3. Confirm how note content splits across sessions (manual or Leo-assisted when enabled).
4. Each **session** has its own delivery row per class group; completing one class does not complete another.

Session detail includes plan notes, rich **content blocks**, teaching deck, resources, publish visibility, and post-complete tools.

## Teaching mode

When it is time to deliver:

- Open **Teach** on a session for a fullscreen presenter built from the teaching deck.
- Mark **delivered**, link attendance if used, then **complete** to write scheme coverage.
- Substitutes can be assigned on the session; the **actual teacher** is recorded on completion.

## Publishing for students & parents

Per session you control:

- **Student visibility** — published sessions appear in the student API when enabled.
- **Parent visibility** — caregiver summary when the school enables parent-facing summaries.
- **Admin visibility** — internal review surfaces.

Legacy single **Lesson** records may redirect to their migrated session when present.

## Resources

Attach links, files, or library books to a session (when **Lesson resources** is enabled in school settings). Visibility can be limited to teachers, students, or students and parents.

## Flashcards & homework (after complete)

After a session is **completed** (when features are enabled):

- **Flashcards** — session-scoped decks; Leo can draft cards for review.
- **Homework / practice** — create linked assignments or quizzes from Studio, including Leo-generated practice.
- **Reflection** — short delivery reflection for the teacher journal.

## Analytics

**Lesson analytics** (teacher and admin) reports legacy publish/engagement metrics plus **Lessons v2 delivery coverage**: completed deliveries and scheme items by class group and week plan.

## What changed from the old flow

- **Lesson bank import** is removed; reuse content via approved notes and week cloning.
- **Draft → published** on standalone lessons is superseded by week plans, sessions, and delivery lifecycle.
- Student web engagement metrics remain; mobile owns detailed view tracking.

## Collaboration

Where enabled on legacy lessons, section comments and `@` mentions may still apply. New work should use session/week planning and school communication tools.
