# Assess UX04 design reference kit

This kit contains the Codex implementation prompt and six product-owner-approved **concept** wireframes.

1. Copy/unzip the kit into the **root of `edusentrix-web-nextjs`** as `docs/assess/ux/UX04_REFERENCE_KIT/` or another folder Codex can read.
2. Open Codex/Cursor in the `edusentrix-web-nextjs` repository.
3. Provide the contents of `ASSESS_UX04_CODEX_PROMPT.md` or tell Codex to read and execute that file.
4. The image boards are **visual direction only**. Several illustrations depict capabilities or semantics not yet implemented (AI marking, result release, class-only packet assignment). The prompt explicitly corrects them. Existing app logic wins.
