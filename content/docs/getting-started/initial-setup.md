# Initial Setup Guide

This guide walks you through the essential setup steps to get your school up and running on EduSentrix.

## Step 1: Create Academic Period

The academic period defines your school's term and academic year. This is the foundation for all other operations.

### How to Create an Academic Period

1. Navigate to your **Dashboard**
2. Look for the **Academic Period** card
3. Click the **"Create period"** button (it will have a shimmer effect if it's your next step)
4. Fill in the required information:
   - **Academic Year**: e.g., "2024/2025"
   - **Term**: e.g., "First Term", "Second Term", "Third Term"
   - **Start Date**: When the term begins
   - **End Date**: When the term ends
5. Click **"Create Period"**

### Why This Matters

The academic period is used to:
- Track term progress
- Organize fee collection by term
- Generate term-specific reports
- Monitor academic performance over time

## Step 2: Create Class Groups

Class groups organize students into manageable classes. You can create multiple class groups per grade level.

### How to Create Class Groups

1. From the **Dashboard**, click **"Create Class"** in Quick Actions
2. Select the grades you want to create classes for
3. Configure each grade:
   - **Number of Classes**: How many class groups per grade
   - **Naming Pattern**:
     - Letters (A, B, C...)
     - Numbers (1, 2, 3...)
     - Custom names (Rose, Sunflower, etc.)
4. Preview your class names before creating
5. Optionally assign default subjects to all classes
6. Click **"Create Class Groups"**

### Tips

- You can create different numbers of classes for different grades
- For example: Primary 1 might have 2 classes, while JHS1 has only 1
- Custom names allow for creative class naming like "JHS 1 Rose" or "JHS2 Sunflower"

## Step 3: Add Teachers

Teachers are essential for managing classes and subjects.

### How to Add a Teacher

1. Click **"Add Teacher"** in Quick Actions
2. Fill in **Basic Information**:
   - First Name
   - Last Name
   - Email (required)
   - Phone (optional)
3. Upload a **Photo** (optional but recommended)
4. Set **Status**: Active or Inactive
5. **Assign Subjects**: Select which subjects this teacher teaches
6. **Assign Homeroom** (optional): Make this teacher a homeroom teacher for a specific class
7. Click **"Create Teacher"**

### Teacher Assignments

- **Subject Assignment**: Teachers can teach multiple subjects
- **Homeroom Teacher**: One teacher per class group who manages that class
- Teachers can be assigned to multiple classes but only one homeroom class

## Step 4: Add Students

Now you're ready to enroll students!

### How to Add a Student

1. Click **"Add New Student"** in Quick Actions
2. **Step 1 - Basic Information**:
   - First Name, Middle Name (optional), Last Name
   - Admission Number (optional but recommended)
   - Sex
   - Date of Birth
   - Enrollment Date
3. **Step 2 - Photo & Status**:
   - Upload student photo
   - Set status (Active, Inactive, or Withdrawn)
4. **Step 3 - Grade & Class**:
   - Select Grade
   - Select Class Group (filtered by selected grade)
5. **Step 4 - Subject Overrides** (optional):
   - Add additional subjects
   - Remove subjects if needed
6. Click **"Create Student"**

### Student Assignment

- Students must be assigned to both a **Grade** and a **Class Group**
- The class group must belong to the selected grade
- Subject assignments are inherited from the class group but can be customized

## What's Next?

Once you've completed these steps, you'll have full access to all features:
- Fee management
- Reports and analytics
- Bulk operations
- Advanced settings

Congratulations! Your school is now set up on EduSentrix.
