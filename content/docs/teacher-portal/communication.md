# Teacher Communication

Communicate with parents, other teachers, and school administrators. Access communication tools from `/teacher/communication`.

## Overview

The teacher communication module includes:
- **Messages**: Thread-based messaging with parents and staff
- **Notices**: Create and send school-wide or class-specific notices
- **Escalations**: Escalate student issues to administrators

## Messages

### Accessing Messages

Navigate to **Communication** → **Messages** (`/teacher/communication/messages`).

### Sending a Message

1. Click **New Message** or open an existing thread
2. Select the recipient (parent, teacher, or admin)
3. Type your message
4. Send

### Message Threads

Messages are organized into threads:
- Each conversation has its own thread
- View message history within a thread
- Reply directly within the thread view at `/teacher/communication/messages/[threadId]`

## Notices

### Creating a Notice

1. Navigate to **Communication** → **Notices** (`/teacher/communication/notices`)
2. Click **New Notice** to go to the creation page
3. Fill in:
   - **Title**: Notice heading
   - **Content**: Notice body
   - **Target Audience**: Choose class(es) or school-wide
4. Publish the notice

### Viewing Notices

- See all notices you've created
- Track read/delivery status
- Edit or archive notices

## Escalations

### What are Escalations?

Escalations allow teachers to formally raise student concerns to school administrators. Use them for:
- Behavioural issues
- Academic concerns
- Attendance problems
- Welfare issues

### Creating an Escalation

1. Navigate to **Communication** → **Escalations** (`/teacher/communication/escalations`)
2. Click **New Escalation**
3. Select the student
4. Describe the issue
5. Set priority level
6. Submit

### Tracking Escalations

- View the status of your escalations
- Receive updates when administrators respond
- Track resolution progress

## Notifications

Access your notification center at `/teacher/notifications`:
- View all notifications
- Mark as read
- Filter by type
- Stay informed about approvals, messages, and system events

## Calendar

View the academic calendar at `/teacher/calendar`:
- See school-wide events
- View your class schedule
- Check upcoming deadlines

## Journal

Record class journal entries at `/teacher/journal`:
- Log daily observations
- Track student progress
- Note classroom events
- Entries are organized by class group

## Best Practices

1. **Professional Tone**: Maintain a professional communication style
2. **Timely Responses**: Reply to parent messages promptly
3. **Document Issues**: Use escalations for formal issue tracking
4. **Regular Updates**: Post notices for important class information
5. **Check Notifications**: Review notifications daily
