# Managing Academic Periods

Learn how to create and manage academic periods in EduSentrix.

## What is an Academic Period?

An academic period represents a term within an academic year. It defines:
- The time frame for the term
- Progress tracking
- Fee collection periods
- Report generation windows

## Creating an Academic Period

### Step-by-Step Process

1. **Navigate to Dashboard**
2. Look for the **Academic Period** card
3. Click **"Create period"** button
4. Fill in the required information:
   - **Academic Year**: e.g., "2024/2025", "2024-2025"
   - **Term**: e.g., "First Term", "Second Term", "Third Term"
   - **Start Date**: When the term begins
   - **End Date**: When the term ends
5. Click **"Create Period"**

### Important Notes

- Only one academic period can be active at a time
- The academic period must be created before you can:
  - Create class groups
  - Add teachers
  - Add students
  - Collect fees

## Academic Period Details

### Year Label

The academic year identifier:
- Format examples: "2024/2025", "2024-2025", "2024"
- Used in reports and records
- Helps organize multi-year data

### Term

The specific term within the academic year:
- Common terms: First Term, Second Term, Third Term
- Can be customized: "Term 1", "Semester 1", etc.
- Used for organization and reporting

### Date Range

- **Start Date**: First day of the term
- **End Date**: Last day of the term
- Used to calculate:
  - Term progress percentage
  - Days remaining
  - Fee collection periods

## Term Progress Tracking

### Progress Indicator

The dashboard shows:
- **Current Term**: Active term name
- **Progress Percentage**: How far through the term you are
- **Visual Progress Bar**: Visual representation of term progress
- **Start and End Dates**: Displayed for reference

### Progress Calculation

Progress is calculated as:
- Days elapsed since start date
- Divided by total days in term
- Displayed as a percentage

## Managing Multiple Periods

### Creating New Periods

When a term ends:
1. Create a new academic period for the next term
2. The previous period remains in records
3. Historical data is preserved
4. Reports can be generated for any period

### Period History

- All past periods are stored
- Can be viewed in reports
- Used for year-over-year comparisons
- Historical fee records maintained

## Best Practices

1. **Plan Ahead**: Create periods before they start
2. **Accurate Dates**: Use exact start and end dates
3. **Consistent Naming**: Use consistent year and term formats
4. **Regular Updates**: Review progress regularly
5. **Term Transitions**: Plan for smooth transitions between terms

## Troubleshooting

### Cannot Create Period
- Check if another period is already active
- Verify date format is correct
- Ensure end date is after start date

### Progress Not Updating
- Verify dates are correct
- Check system date/time settings
- Refresh the dashboard

### Period Not Showing
- Ensure period is marked as current
- Check if period dates are valid
- Verify user permissions
