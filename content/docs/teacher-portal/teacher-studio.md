# Teacher Studio

The Teacher Studio is your hub for creating and managing assignments, quizzes, resources, and rubrics. Access it from the teacher sidebar at `/teacher/studio`.

## Overview

Teacher Studio provides:
- **Assignments**: Create, distribute, and grade assignments
- **Quizzes**: Build quiz-based assessments
- **Resources**: Upload and share teaching materials
- **Rubrics**: Create reusable grading rubrics
- **Submissions**: View and grade student work
- **Projects**: Manage longer-term student projects

## Studio Dashboard

The main studio page displays:
- Quick stats for assignments, quizzes, and submissions
- Recent activity
- Quick access to create new items

## Assignments

### Creating an Assignment

1. Navigate to **Studio** → **Assignments** → **New**
2. Fill in assignment details:
   - **Title**: Assignment name
   - **Description**: Instructions and context
   - **Class**: Select target class
   - **Subject**: Choose the subject
   - **Due Date**: Submission deadline
   - **Total Points**: Maximum score
   - **Attachments**: Upload reference files
3. Optionally attach a **Rubric** for structured grading
4. Save or publish the assignment

### Managing Assignments

From the Assignments page (`/teacher/studio/assignments`):
- View all assignments with status indicators
- Filter by class, subject, or status
- Edit draft assignments
- View submission counts
- Access individual assignment details

### Grading Submissions

1. Click on an assignment to view submissions
2. Open each submission to review student work
3. Assign scores (with optional rubric)
4. Add feedback comments
5. Mark as graded

## Quizzes

### Creating a Quiz

1. Navigate to **Studio** → **Quizzes** → **New**
2. Fill in quiz details:
   - **Title**: Quiz name
   - **Description**: Context and instructions
   - **Class**: Target class
   - **Subject**: Subject area
   - **Duration**: Time limit (optional)
   - **Total Points**: Maximum score
3. Add questions with answer options
4. Save or publish

### Quiz Management

- View all quizzes with submission status
- Track completion rates
- View quiz results and analytics

## Resources

### Uploading Resources

1. Navigate to **Studio** → **Resources**
2. Click **Upload Resource**
3. Select file(s) to upload
4. Add title and description
5. Choose target class/subject

Resources are uploaded via UploadThing and stored securely.

## Rubrics

### Creating a Rubric

1. Navigate to **Studio** → **Rubrics**
2. Click **Create Rubric**
3. Define criteria and performance levels
4. Set point values for each level
5. Save for reuse across assignments

Rubrics can be attached to any assignment for consistent, structured grading.

## Submissions

### Viewing Submissions

Navigate to **Studio** → **Submissions** to see all student submissions across assignments and quizzes:
- Filter by assignment, class, or grading status
- Bulk grading options
- Individual submission detail view

## Best Practices

1. **Clear Instructions**: Write detailed assignment descriptions
2. **Reasonable Deadlines**: Give students adequate time
3. **Use Rubrics**: Attach rubrics for fair, consistent grading
4. **Timely Feedback**: Grade submissions promptly
5. **Share Resources**: Upload reference materials for students
