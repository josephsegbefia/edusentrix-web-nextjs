# Initial Setup Guide

This guide walks you through the essential setup steps to get your school up and running on EduSentrix.

## Step 1: Create Academic Period

The academic period defines your school's term and academic year. This is the foundation for all other operations.

### How to Create an Academic Period

1. Navigate to your **Dashboard**
2. Look for the **Academic Period** card
3. Click the **"Create period"** button (it will have a shimmer effect if it's your next step)
4. Fill in the required information:
   - **Academic Year**: e.g., "2024/2025"
   - **Term**: e.g., "First Term", "Second Term", "Third Term"
   - **Start Date**: When the term begins
   - **End Date**: When the term ends
5. Click **"Create Period"**

### Why This Matters

The academic period is used to:
- Track term progress
- Organize fee collection by term
- Generate term-specific reports
- Monitor academic performance over time

## Step 2: Create Class Groups

Class groups organize students into manageable classes. You can create multiple class groups per grade level.

### How to Create Class Groups

1. From the **Dashboard**, click **"Create Class"** in Quick Actions
2. Select the grades you want to create classes for
3. Configure each grade:
   - **Number of Classes**: How many class groups per grade
   - **Naming Pattern**:
     - Letters (A, B, C...)
     - Numbers (1, 2, 3...)
     - Custom names (Rose, Sunflower, etc.)
4. Preview your class names before creating
5. Optionally assign default subjects to all classes
6. Click **"Create Class Groups"**

### Tips

- You can create different numbers of classes for different grades
- For example: Primary 1 might have 2 classes, while JHS1 has only 1
- Custom names allow for creative class naming like "JHS 1 Rose" or "JHS2 Sunflower"

## Step 3: Add Teachers

Teachers are essential for managing classes and subjects. The Teachers Management page provides a premium interface for managing your teaching staff.

### How to Add a Teacher

**Option 1: From Dashboard**
1. Click **"Add Teacher"** in Quick Actions on the dashboard
2. Fill in the teacher information form

**Option 2: From Teachers Page**
1. Navigate to **Teachers** (`/admin/teachers`)
2. Click **"Add Teacher"** button in the header
3. Or use the command palette (`Ctrl+K` / `⌘K`) and select "Add a new teacher"

**Teacher Information Form:**
1. **Basic Information**:
   - First Name (required)
   - Last Name (required)
   - Email (required) - Used for account access
   - Phone (optional)
2. **Professional Details** (optional):
   - Employee ID
   - Department
   - Hire Date
3. Upload a **Photo** (optional but recommended)
4. Set **Status**:
   - Active: Currently teaching
   - Inactive: Temporarily unavailable
   - On Leave: Currently on leave
   - Terminated: No longer employed
5. **Assign Subjects**: Select which subjects this teacher teaches (can select multiple)
6. **Assign Homeroom** (optional): Make this teacher a homeroom teacher for a specific class group
7. Click **"Create Teacher"**

### Managing Teachers

After creating teachers, you can manage them from the **Teachers** page (`/admin/teachers`):

- **View Modes**: Switch between card view (default) and table view
- **Search**: Use the search bar to find teachers by name, email, or employee ID
- **Filters**: Filter by subject, class group, department, or status
- **Sort**: Sort by name, hire date, or status
- **Bulk Actions**: Select multiple teachers for batch operations
- **Command Palette**: Press `Ctrl+K` / `⌘K` for quick actions

### Teacher Assignments

- **Subject Assignment**: Teachers can teach multiple subjects
- **Homeroom Teacher**: One teacher per class group who manages that class
- **Class Assignments**: Teachers can be assigned to teach specific subjects in specific classes
- **Assignment Management**: View and manage all assignments from the teacher's detail page

### Teacher Detail Page

Click on any teacher card or row to view their detailed profile:

- **Overview Tab**: Personal info, professional details, subject assignments, and quick actions
- **Assignments Tab**: View and manage all class and subject assignments
- **Performance Tab**: Teaching performance metrics (coming soon)
- **Attendance Tab**: Attendance records and leave management (coming soon)
- **Documents Tab**: Upload and manage certifications and documents (coming soon)
- **Notes Tab**: Internal notes and observations (coming soon)
- **Activity Tab**: Complete audit log of all teacher-related actions (coming soon)

## Step 4: Add Students

Now you're ready to enroll students!

### How to Add a Student

1. Click **"Add New Student"** in Quick Actions
2. **Step 1 - Basic Information**:
   - First Name, Middle Name (optional), Last Name
   - Admission Number (optional but recommended)
   - Sex
   - Date of Birth
   - Enrollment Date
3. **Step 2 - Photo & Status**:
   - Upload student photo
   - Set status (Active, Inactive, or Withdrawn)
4. **Step 3 - Grade & Class**:
   - Select Grade
   - Select Class Group (filtered by selected grade)
5. **Step 4 - Subject Overrides** (optional):
   - Add additional subjects
   - Remove subjects if needed
6. Click **"Create Student"**

### Student Assignment

- Students must be assigned to both a **Grade** and a **Class Group**
- The class group must belong to the selected grade
- Subject assignments are inherited from the class group but can be customized
